# Публикация обновления сайта NazarovES.github.io

## Что в этом архиве

| Путь | Содержимое |
|---|---|
| `index.html`, `assets/`, `classificationmge/`, `mapping/`, `ids-converter/`, `data/` | Готовая сборка сайта — это корень репозитория (то, что отдаёт GitHub Pages) |
| `app/` | Полные исходники проекта (Vite + React + TypeScript + Tailwind) — для дальнейшего редактирования |
| `ids-converter/` | **Новая страница** — конвертер HTML-отчётов ifctester в IDS 0.9.3 (карточка уже добавлена на главную) |

## Вариант 1 — через веб-интерфейс GitHub (без командной строки)

1. Откройте `https://github.com/NazarovES/NazarovES.github.io` (войдите в аккаунт **NazarovES**).
2. Удалите старые файлы сборки: папку `assets/` и файл `index.html` в корне (кнопка `⋯` → Delete). Папки `classificationmge/`, `mapping/`, `data/` удалять не нужно — они будут перезаписаны, но если хотите чистый деплой — удалите и их.
3. Нажмите **Add file → Upload files** и перетащите **содержимое** архива (все папки и `index.html` из корня архива, а не саму папку `site`).
4. Внизу: Commit directly to the `main` branch → **Commit changes**.

> Веб-загрузка перезаписывает файлы по именам. Хэши ассетов (`assets/*.js`, `*.css`) в новой сборке другие, поэтому шаг 2 важен — иначе в `assets/` останутся старые файлы (не страшно, но лишний вес).

## Вариант 2 — через git (командная строка)

```bash
git clone https://github.com/NazarovES/NazarovES.github.io.git
cd NazarovES.github.io
git rm -r assets index.html classificationmge mapping data 2>/dev/null
# распаковать архив и скопировать СОДЕРЖИМОЕ в корень:
unzip NazarovES-site-update.zip -d /tmp/site-update
cp -r /tmp/site-update/. .
git add -A
git commit -m "Восстановлены исходники (app/) + IDS-конвертер (/ids-converter/)"
git push origin main
```

## Работа с исходниками (папка app/)

```bash
cd app
npm install        # Node 20+
npm run build      # сборка в dist/
```

Собранный `dist/` и есть то, что лежит в корне репозитория. Страницы: `src/pages/`, точки входа: `src/entries/`, HTML-входы: `index.html` + подпапки (`classificationmge/index.html` и т.д.). Мультипейдж-сборка настроена в `vite.config.ts` (`rollupOptions.input`).
